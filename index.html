Go Loop Audio provide technical services to the music production and related creative industries

Software

We have many years experience writing audio software powering real-time audio mixing, DAW plugins, hardware configuration apps, digitial audio routing, audio metadata management and much more. We focus on the system programming level languages, C and C++, using cross-platform libraries like the JUCE framework to be able to target Windows, macOS, Linux and Embedded operating systems. Whether you need help maintaining/improving existing software or would like to write new software we can help you out!

Technology

We are industry leading experts in all the latest audio technology protocols. Professional studios often span multiple technologies such as MIDI, OSC, MusicXML, Timecode, MADI, SPDIF, SMPTE/MTC, Sync, Dante/Ravenna, TSL UMD, SNMP and TCP/IP + UDP. Whether you need help in choosing the best in class producsts that handle these protocls, or you need help advising bridging or transitioning from legacy to emerging techlogies, or writing custom software to integrate with existing technology, we have you covered.
